# Demo Website Assets

Folder ini dipakai untuk gambar kartu demo di section portofolio.

- Ganti file SVG sesuai kategori dengan screenshot/mockup website asli.
- Nama file yang sudah dipakai: `cafe-resto.svg`, `warung.svg`, `laundry.svg`, `barbershop.svg`, `fashion.svg`, `villa.svg`, `travel.svg`, `company.svg`, `rental.svg`, `peternakan.svg`, `marketplace.svg`, `landing.svg`.
- Jika ingin pakai PNG/JPG/WebP, simpan di folder ini lalu update `imageUrl` pada data portofolio.
- Rekomendasi ukuran: 1200x800 px, WebP untuk produksi.
